# 01 環境構築

## 前提条件

| 項目 | 確認方法 | 備考 |
|---|---|---|
| macOS | — | iOS ビルドには Mac が必須 |
| Xcode 16 以上 | App Store | Command Line Tools も必要 |
| Apple Developer アカウント | developer.apple.com | 実機インストールに必要（無料でも可） |
| iPhone 実機 (iOS 15.1 以上) | — | **シミュレータ不可**（後述） |
| Node.js 20 以上 | `node -v` | |
| npm 10 以上 | `npm -v` | |

### Expo Go ではなく Dev Client を使用する理由

このデモアプリは **`react-native-beacon-radar`** という BLE ネイティブモジュールを使用します。ネイティブモジュールは Expo Go アプリには含まれていないため、**Expo Go で起動するとクラッシュします**。

代わりに `expo prebuild` でネイティブプロジェクトを生成し、Xcode でビルドした Dev Client（開発クライアントアプリ） を実機にインストールして使います。

### シミュレータではなく実機を使用する理由

iBeacon は Bluetooth Low Energy (BLE) のビーコン信号です。iOS シミュレータは Bluetooth ハードウェアを持たないため、**ビーコン信号の検出は実機のみ**対応しています。

### EAS（クラウドビルド）ではなく Xcode を使用する理由

Expo にはクラウドでアプリをビルドできる **EAS Build** があり、これを使えば Xcode 無し（Windows でも）で iOS アプリをビルドできます。ただし **EAS でビルドしたアプリを iPhone 実機にインストールするには ad hoc 配布となり、[有料の Apple Developer Program（年 $99）が必須](https://docs.expo.dev/build/internal-distribution/)** です（無料の Apple ID では実機に入れられません）。

このデモは 無料で動作確認できることを優先し、無料の Apple ID（Personal Team）で実機インストールできる ローカルの Xcode ビルドを採用しています。そのため以降の手順は Xcode を前提に進めます。

## Xcode のセットアップ

### 1. Xcode インストール

App Store から Xcode をインストールします（約 10 GB）。

### 2. Command Line Tools の設定

1. Xcode を開き、画面上部のメニューから **Xcode > Settings > Locations で Command Line Tools** を選択

### 3. 実機を開発者モードで認識させる

1. iPhone を USB で Mac に接続
2. Xcode を開き、メニュー **Window > Devices and Simulators** を選択
3. 接続した iPhone が表示されれば OK
4. iPhone 側で「このコンピュータを信頼しますか？」ダイアログが出た場合は「信頼」を選択
5. iPhone の **設定 > プライバシーとセキュリティ > デベロッパモード** をオンにする

## Apple Developer アカウントの登録（無料）

実機にアプリをインストールするには Xcode でアプリへ署名（Signing）する必要があり、そのために Apple ID が必要です。**自分の端末で動かすだけなら、年額 $99 の有料の Apple Developer Program への加入は不要**で、無料の Apple ID（Personal Team）で署名できます。

### 1. Apple ID を用意する

すでに iPhone で使っている Apple ID をそのまま使えます。持っていない場合は [appleid.apple.com](https://appleid.apple.com/) から無料で作成します。

### 2. Xcode に Apple ID を登録する

1. Xcode を開き、メニュー **Xcode > Settings > Apple Accounts** を開く
2. 右下の **「Add Apple Account…」** をクリック
3. メールアドレス（or 電話番号）とパスワードを入力してサインイン
4. 登録すると **Personal Team**（個人用の無料チーム）が利用可能になる

これで「03 動作確認」の Signing 設定で、この Personal Team を **Team** に選択できるようになります。

> **無料登録の制限**: 無料の Personal Team で署名したアプリは **7 日間で有効期限が切れます**（期限後は再ビルドで再インストール）。また Push 通知など一部の機能は使えません。継続的な配布や TestFlight 利用には有料の Apple Developer Program が必要ですが、このデモの動作確認には無料登録で十分です。

## Node.js・npm のインストール（未インストールの場合）

### nvm を使う場合

[nvm](https://github.com/nvm-sh/nvm) は Node.js 専用のバージョン管理ツールです。

```bash
# nvm のインストール
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# Node.js のインストール（LTS 版）
nvm install --lts
nvm use --lts

# バージョン確認
node -v   # v2x.x.x
npm -v    # 1x.x.x
```

### mise を使う場合

[mise](https://mise.jdx.dev/) は Node.js 以外（Python・Ruby など）もまとめて管理できる汎用ツールです。

```bash
# mise のインストール
curl https://mise.run | sh

# Node.js のインストール（LTS 版）
mise use --global node@lts

# バージョン確認
node -v   # v2x.x.x
npm -v    # 1x.x.x
```
