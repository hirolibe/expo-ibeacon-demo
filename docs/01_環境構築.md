# 01 環境構築

## 前提条件

| 項目 | 確認方法 | 備考 |
|---|---|---|
| macOS | — | iOS ビルドには Mac が必須 |
| Xcode 16 以上 | App Store | Command Line Tools も必要 |
| Apple Developer アカウント | developer.apple.com | 実機インストールに必要（無料でも可） |
| iPhone 実機 (iOS 15.1 以上) | — | **シミュレータ不可**（後述） |
| Node.js 20 以上 | `node -v` | |
| npm 10 以上 | `npm -v` | |

---

## なぜ Expo Go は使えないのか

このデモアプリは **`react-native-beacon-radar`** という BLE ネイティブモジュールを使用します。ネイティブモジュールは Expo Go アプリには含まれていないため、**Expo Go で起動するとクラッシュします**。

代わりに `expo prebuild` でネイティブプロジェクトを生成し、Xcode でビルドした **開発ビルド（Dev Client）** を実機にインストールして使います。

---

## なぜシミュレータは使えないのか

iBeacon は Bluetooth Low Energy (BLE) のビーコン信号です。iOS シミュレータは Bluetooth ハードウェアを持たないため、**ビーコン信号の検出は実機のみ**対応しています。

---

## Xcode のセットアップ

### 1. Xcode インストール

App Store から Xcode をインストールします（約 10 GB）。

### 2. Command Line Tools の設定

```bash
xcode-select --install
# または Xcode > Settings > Locations で Command Line Tools を選択
```

### 3. 実機を開発者モードで認識させる

1. iPhone を USB または Wi-Fi で Mac に接続
2. Xcode を開き、メニュー **Window > Devices and Simulators** を選択
3. 接続した iPhone が表示されれば OK
4. iPhone 側で「このコンピュータを信頼しますか？」ダイアログが出た場合は「信頼」を選択
5. iOS 16 以降の場合、iPhone の **設定 > プライバシーとセキュリティ > 開発者モード** をオンにする

## Node.js・npm のインストール（未インストールの場合）

[nvm](https://github.com/nvm-sh/nvm) を使うと複数バージョンを管理しやすいです。

```bash
# nvm のインストール
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# Node.js 20 のインストール
nvm install 20
nvm use 20

# バージョン確認
node -v   # v20.x.x
npm -v    # 10.x.x
```

---

## Expo CLI のインストール

```bash
npm install -g expo-cli
# または npx expo ... で都度実行することもできます（グローバルインストール不要）
```

## プロジェクトの依存パッケージをインストール

このデモプロジェクトのルートで以下を実行します。

```bash
cd /path/to/expo-ibeacon-demo
npm install
```

インストール後、依存関係の整合性を確認します。

```bash
npx expo-doctor
```

問題がなければ次のステップ（コーディング / ビルド）に進みます。
