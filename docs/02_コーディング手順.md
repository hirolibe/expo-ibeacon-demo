## Expo プロジェクトの新規作成

```bash
npx create-expo-app expo-ibeacon-demo --template blank-typescript
cd expo-ibeacon-demo
```

このコマンドで以下のファイルが自動生成される。

| ファイル | 備考 |
|---|---|
| `package.json` | Expo 基本依存のみ（`babel-preset-expo` は**含まれない**） |
| `babel.config.js` | `babel-preset-expo` を参照しているが、パッケージ自体は含まれない |
| `App.tsx` | サンプル画面（後で書き換える） |
| `index.ts`, `app.json`, `tsconfig.json`, `.gitignore` | そのまま使用 |

`babel.config.js` は `babel-preset-expo` を参照しているにもかかわらず `package.json` には含まれないため、次の「依存パッケージの追加」ステップで明示的にインストールする。

## 依存パッケージの追加

```bash
npm install react-native-beacon-radar expo-dev-client expo-build-properties
npx expo install babel-preset-expo
```

| パッケージ | 役割 |
|---|---|
| `react-native-beacon-radar` | iBeacon スキャンのネイティブモジュール |
| `expo-dev-client` | Expo Go の代わりに使う開発ビルドランタイム |
| `expo-build-properties` | `app.json` から iOS/Android のビルド設定を制御するプラグイン |
| `babel-preset-expo` | Metro バンドラーが使用する Babel プリセット（`npx expo install` で SDK 対応バージョンを指定） |

## src/beaconScanner.ts の作成

iBeacon スキャンのロジックを切り出したユーティリティです。

```typescript
import { DeviceEventEmitter, EmitterSubscription } from 'react-native';
import * as BeaconRadar from 'react-native-beacon-radar';

// ======================================================
// 自分のビーコンの UUID に書き換えてください
// ======================================================
export const BEACON_UUID = 'YOUR-BEACON-UUID-HERE';

export type DetectedBeacon = {
  uuid: string;
  major: number;
  minor: number;
  rssi: number;
  distance: number;
};

type AuthStatus = string | { status: string };

async function requestPermission(): Promise<boolean> {
  const raw = (await (BeaconRadar as unknown as {
    getAuthorizationStatus: () => Promise<AuthStatus>;
  }).getAuthorizationStatus()) as AuthStatus;

  const status = typeof raw === 'string' ? raw : raw.status;

  if (status === 'authorizedWhenInUse' || status === 'authorizedAlways') {
    return true;
  }

  const result = (await BeaconRadar.requestWhenInUseAuthorization()) as AuthStatus;
  const granted = typeof result === 'string' ? result : result.status;
  return granted === 'authorizedWhenInUse' || granted === 'authorizedAlways';
}

let subscription: EmitterSubscription | null = null;

export async function startScan(onDetected: (beacons: DetectedBeacon[]) => void): Promise<void> {
  const permitted = await requestPermission();
  if (!permitted) {
    throw new Error('位置情報の権限が許可されていません');
  }

  subscription = DeviceEventEmitter.addListener(
    'onBeaconsDetected',
    (raw: DetectedBeacon[] | DetectedBeacon | undefined | null) => {
      const beacons: DetectedBeacon[] = Array.isArray(raw) ? raw : raw ? [raw] : [];
      if (beacons.length > 0) {
        onDetected(beacons);
      }
    },
  );

  BeaconRadar.startScanning(BEACON_UUID, {
    useForegroundService: false,
    useBackgroundScanning: false,
  });
}

export function stopScan(): void {
  if (subscription) {
    subscription.remove();
    subscription = null;
  }
  try {
    BeaconRadar.stopScanning();
  } catch {
    // 既に停止済みの場合は無視
  }
}
```

### BEACON_UUID の書き換え

`BEACON_UUID` は自分の iBeacon のプロパティから確認します。サンワサプライ MM-BLEBC3 の場合、付属の管理ツールや [LightBlue](https://punchthrough.com/lightblue/) などの BLE スキャンアプリで確認できます。

```typescript
// 例
export const BEACON_UUID = 'E2C56DB5-DFFB-48D2-B060-D0F5A71096E0';
```

### コード解説

| 関数 | 役割 |
|---|---|
| `requestPermission()` | 位置情報権限の状態を確認し、未許可なら許可ダイアログを表示 |
| `startScan(onDetected)` | 権限確認後、`BeaconRadar.startScanning()` でスキャン開始。`DeviceEventEmitter` で `onBeaconsDetected` イベントを購読し、検出時にコールバックを呼ぶ |
| `stopScan()` | イベント購読を解除し `BeaconRadar.stopScanning()` でスキャン停止 |

`react-native-beacon-radar` は UUID 単位でスキャン Region を登録する仕様のため、スキャン対象の UUID を `startScanning()` に渡す必要があります。Major / Minor の絞り込みは JS 側で行います（このデモでは全件表示）。

## App.tsx の作成

画面とスキャン制御のメインコンポーネントです。

```tsx
import { StatusBar } from 'expo-status-bar';
import { useEffect, useRef, useState } from 'react';
import { Alert, Pressable, StyleSheet, Text, View } from 'react-native';
import { type DetectedBeacon, startScan, stopScan } from './src/beaconScanner';

type ScanState = 'idle' | 'scanning' | 'detected';

export default function App() {
  const [scanState, setScanState] = useState<ScanState>('idle');
  const [latestBeacon, setLatestBeacon] = useState<DetectedBeacon | null>(null);
  const detectedRef = useRef(false);

  useEffect(() => {
    return () => { stopScan(); };
  }, []);

  async function handleStart() {
    detectedRef.current = false;
    setScanState('scanning');
    setLatestBeacon(null);
    try {
      await startScan((beacons) => {
        detectedRef.current = true;
        setScanState('detected');
        setLatestBeacon(beacons[0] ?? null);
      });
    } catch (e) {
      setScanState('idle');
      Alert.alert('エラー', e instanceof Error ? e.message : String(e));
    }
  }

  function handleStop() {
    stopScan();
    setScanState('idle');
    setLatestBeacon(null);
    detectedRef.current = false;
  }

  const isScanning = scanState === 'scanning' || scanState === 'detected';

  return (
    <View style={styles.container}>
      <StatusBar style="auto" />
      <Text style={styles.title}>iBeacon デモ</Text>

      {/* 検出状態に応じてメッセージを切り替え */}
      {scanState === 'detected' && (
        <View style={styles.detectedBox}>
          <Text style={styles.detectedText}>iBeacon信号を検出しました！</Text>
        </View>
      )}
      {scanState === 'scanning' && (
        <View style={styles.scanningBox}>
          <Text style={styles.scanningText}>スキャン中…</Text>
        </View>
      )}
      {scanState === 'idle' && (
        <View style={styles.idleBox}>
          <Text style={styles.idleText}>待機中</Text>
        </View>
      )}

      {/* デバッグ用: 直近の検出ビーコン情報 */}
      {latestBeacon && (
        <View style={styles.beaconInfo}>
          <Text>UUID: {latestBeacon.uuid}</Text>
          <Text>Major: {latestBeacon.major} / Minor: {latestBeacon.minor}</Text>
          <Text>RSSI: {latestBeacon.rssi} dBm</Text>
        </View>
      )}

      {/* スキャン開始 / 停止ボタン */}
      <View style={styles.buttonArea}>
        {!isScanning ? (
          <Pressable style={[styles.button, styles.buttonStart]} onPress={handleStart}>
            <Text style={styles.buttonText}>スキャン開始</Text>
          </Pressable>
        ) : (
          <Pressable style={[styles.button, styles.buttonStop]} onPress={handleStop}>
            <Text style={styles.buttonText}>スキャン停止</Text>
          </Pressable>
        )}
      </View>
    </View>
  );
}
```
