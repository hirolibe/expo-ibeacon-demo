# 03 動作確認（実機 iOS）

## 事前準備チェックリスト

- [ ] Mac に Xcode がインストールされている
- [ ] iPhone が USB または Wi-Fi で Mac に接続されている
- [ ] `npm install` が完了している
- [ ] `src/beaconScanner.ts` の `BEACON_UUID` を自分のビーコンの UUID に書き換えた
- [ ] iBeacon 端末（電池が入っており電波を発信している）が手元にある

---

## ネイティブプロジェクトの生成（prebuild）

```bash
npx expo prebuild --platform ios
```

このコマンドは `ios/` ディレクトリを生成します（初回は数分かかります）。

`app.json` の `plugins` に指定した `react-native-beacon-radar` のプラグインが `Info.plist` の Bluetooth・位置情報権限を自動で設定します。

**注意**: `ios/` ディレクトリは `.gitignore` に含まれています。ビルド設定を変えた場合は `npx expo prebuild --clean` で再生成してください。

---

## 実機ビルドと起動

```bash
npx expo run:ios --device
```

接続中の iPhone が表示されるので選択します（番号を入力して Enter）。

**補足: USB 接続は必須？**

完全な USB レスにはできず、**少なくとも一度は USB 接続が必要**です。実機ビルドには「アプリ本体のインストール」と「JS の配信（Metro / Fast Refresh）」の 2 つの通信があり、それぞれ条件が異なります。

- **JS だけの変更**: アプリが入っていれば、同じ Wi-Fi 上の Metro から反映されるため **USB 不要**。
- **アプリ本体のビルド/インストール**: 初回はペアリングと「ネットワーク経由で接続」の有効化のため **USB が必須**。一度設定すれば 2 回目以降は同一 Wi-Fi ならワイヤレスでビルド・インストール可能。

ワイヤレスインストールを有効化する手順:
1. 最初に iPhone を **USB で接続**する
2. Xcode → **Window > Devices and Simulators** で対象 iPhone を選択
3. **「Connect via network」にチェック**を入れる
4. 以降、同じ Wi-Fi にいれば USB を抜いても `npx expo run:ios --device` でワイヤレスにビルドできる

※ ワイヤレスは USB より遅く、署名やビルドのタイミングで不安定になることがあります。初回フルビルドは USB 接続が無難です。

初回は Xcode が CocoaPods の依存パッケージをインストールするため 10〜20 分かかります。2 回目以降は数分で完了します。

ビルドが成功すると、自動的に iPhone に「iBeaconDemo」アプリがインストールされ、起動します。

### Signing エラーが出た場合

```
error: No signing certificate "iOS Development" found
```

1. Xcode で `ios/iBeaconDemo.xcworkspace` を開く
2. **Targets > iBeaconDemo > Signing & Capabilities** を開く
3. **「Team」** に自分の Apple Developer アカウントを選択
4. **「Automatically manage signing」**をオンにする
5. ターミナルに戻って再度 `npx expo run:ios --device`

## アプリの権限を許可する

アプリ初回起動時またはスキャン開始ボタンをタップすると、以下のダイアログが表示されます。

1. **Bluetooth の使用許可** → 「許可」をタップ
2. **位置情報の使用許可** → 「アプリの使用中のみ許可」をタップ

位置情報を「許可しない」にすると iBeacon のスキャンができません。

---

## iBeacon の検出を確認する

1. アプリ画面の **「スキャン開始」** ボタンをタップ
2. 画面が「スキャン中…」に変わる
3. iBeacon 端末をスマートフォンに近づける（目安: 1〜2m 以内）
4. 数秒以内に 「iBeacon信号を検出しました！」 と表示される
5. 画面下部にビーコンの UUID / Major / Minor / RSSI が表示される

## トラブルシュート

### 1. 「iBeacon信号を検出しました！」が表示されない

#### UUID が合っていない

`src/beaconScanner.ts` の `BEACON_UUID` を確認してください。iOS の CoreLocation は、スキャン対象として指定した UUID のビーコンしか検出しません。

UUID の確認方法:
- サンワサプライ MM-BLEBC3: 付属の管理アプリで確認
- [LightBlue](https://apps.apple.com/jp/app/lightblue/id557428110) アプリ（App Store 無料）で BLE デバイスをスキャンし、ビーコンの Advertised UUIDs を確認

#### ビーコンが遠すぎる / 電波が弱い

RSSI が -80 dBm 以下になると検出が不安定になります。ビーコンを 1m 以内に近づけて試してください。

#### Bluetooth がオフになっている

iPhone の設定 > Bluetooth がオンになっていることを確認してください。

---

### 2. 「位置情報の権限が許可されていません」エラーが出る

iPhone の **設定 > プライバシーとセキュリティ > 位置情報サービス > iBeaconDemo** を開き、「このAppの使用中」または「常に」を選択してください。

---

### 3. ビルドが失敗する（CocoaPods エラー）

```bash
cd ios && pod install && cd ..
npx expo run:ios --device
```

それでも解決しない場合は `ios/` を削除して再 prebuild します。

```bash
rm -rf ios/
npx expo prebuild --platform ios --clean
npx expo run:ios --device
```

---

### 4. アプリが起動せずクラッシュする

`expo-dev-client` がインストールされているかを確認してください。

```bash
npm ls expo-dev-client
```

表示されない場合はインストールします。

```bash
npm install expo-dev-client
npx expo prebuild --platform ios --clean
npx expo run:ios --device
```
